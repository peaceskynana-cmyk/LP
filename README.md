# ENCORE

軽音サークルのライブ感想を、Googleフォームの回答CSVからバンド別に整理する静的Webアプリです。

## 起動

Node.js 24などの現行Node.jsで、リポジトリのルートから実行します。追加依存関係やビルドはありません。

```sh
node serve.js
```

既定はポート8000です。必要に応じて `PORT=8001 node serve.js` と指定できます。

## 利用方法

1. Googleフォームの回答スプレッドシートを、CSV（UTF-8）でダウンロードします。
2. 「回答を取り込む」でCSVを選択し、記入者の列を指定します。
3. バンドごとの感想の列にチェックを入れ、表示するバンド名を入力します。
4. 取り込むと、回答行の記入者と感想をセットでバンド別に整理します。空の感想は除外し、記入者が空の回答には行番号付きの表示名を付けます。
5. バンドの「感想を見る」から、記入者付きのテキストをコピー、またはCSVを書き出して共有します。

最初は架空のサンプルを表示します。取り込みは既存データを置き換えます。CSVはヘッダー1行と回答行からなる横持ち形式（バンドごとの感想が別列）に対応します。ファイル上限は5MBです。同じ人が複数回回答した場合は、それぞれ別の回答として人数を数えます。

## 保存と共有

ファイルはサーバーに送信せず、ブラウザ内で処理します。取り込んだデータは同じオリジンのlocalStorageに保存されます。共有端末では、利用後に「サンプルに戻す」で削除してください。ブラウザの保存領域を消去するとデータも消えるため、必要なCSVは別に保管してください。

Googleフォームとの自動同期、複数端末の同期、ユーザー認証、メールなどでの自動送信はありません。コピー機能はブラウザのクリップボード権限が必要です。使えない場合はCSVを書き出してください。CSV出力時には表計算ソフトの数式として解釈され得る値に先頭のアポストロフィを加えます。

## 確認した動作

Playwright / ChromiumでPC・モバイル表示、CSVの列指定、カンマ・改行を含む回答、記入者空欄、再読み込み後の保存、検索、バンド別書き出し、HTML文字列の安全な表示、不正CSVのエラー表示、保存データ削除を確認しています。

## 学祭ライブのフォーム例

画面で確認できた「名前」「カネコアヤノ」「ASIAN KUNG-FU GENERATION」「クリープハイプ」の構成に対応しています。「名前」を記入者に選び、バンド名の列を感想として取り込みます。スクリーンショット外のバンドも、CSVに列があれば同じように選択できます。

`assets/feedback-example.csv` は同じ見出しと架空の回答を使ったお試しファイルです。取り込み画面からダウンロードできます。実際のフォーム回答は含まれていません。
